## 能做什么

- **准心**：十字、圆环、实心圆与圆心；实时预览、抗锯齿、几何居中、方向键每次 1 物理像素。默认不随系统 DPI 放大尺寸。
- **击杀提示**：每次击杀独立条目；单矩形展开、纵向收束、四次方缓出；文字、颜色、位置和时间可调。
- **实时统计**：K/D/A、回合击杀、爆头击杀比例、可获得的伤害与经济；逐项显示模式、拖拽、网格与边缘吸附。
- **键鼠显示**：逐键 A/B 模式、可配置按键；鼠标左右中键/滚轮高亮；固定面板内自适应缩小轨迹，闲置归中。
- **显示性能**：保留视觉树、缓存与对象复用、12 组轨迹折线、同帧更新合并；1–240 FPS 自定义目标，空闲时停止动画刷新。

## 换电脑安装

1. 将 `ReticleLab-0.2.10-windows-x64.zip` 整包复制到新电脑并解压。
2. 运行 `Install-ReticleLab.cmd`。首次信任开发证书时会出现系统提权提示；安装继续在原用户账户进行。安装器自动关闭旧版目标包进程，保留配置。
3. 安装/启用 Xbox Game Bar，按 **Win + G** 打开并固定 Reticle 控件。
4. 如需 CS2 数据：在新电脑打开设置 → GSI → 启动/检查接收，然后运行 `Setup-GSI.cmd` 并重启 CS2。脚本探测 Steam 库，使用**新电脑生成的 token**，不复用开发者配置。

无需另装 .NET 或 Visual Studio。需 Windows 10 build 19041+ / Windows 11 x64、Xbox Game Bar。包内包含微软 x64 依赖和公开证书，私钥不包含在内。它需要 MSIX 安装，不是免安装绿色版；证书有效期和系统策略仍适用。

## 数据口径必须看清

| 显示 | 实际含义 |
| --- | --- |
| 武器名 | 当前手持兜底，不能确定为击杀武器 |
| 伤害数字 | 相邻本人 GSI 的 `round_totaldmg` 差值，标为“更新增量”；不是目标伤害 |
| 同次更新多杀 | 分别显示，同一更新总量重复标注，不能相加或均分成目标伤害 |
| — / 0 | 缺失或没有可靠基线 / 字段存在但没有增加 |
| 爆头命中、身体命中 | 没有可靠逐次事件；按钮明确为样式演示 |
| 准备阶段降低透明度 | 整个冻结阶段，不是购买菜单检测 |

仅接受 provider 与 player 身份一致的本人参战数据。初次接入、重连不补播旧击杀。HTML 是离线视觉原型，其中的命中/购买菜单/统计模拟不代表 GSI 支持。

## 开发与验证

Windows x64 + .NET SDK 10，执行 `native/scripts/build.ps1`；Python 3 与 Node.js 用于辅助烟测。四份 Noto 字体依据 OFL 随源码提供，构建不要求安装 CS2。详见 [构建与签名](native/DEVELOPMENT-SIGNING.md)。

132 项核心检查、实际 HTTP 接收/鼠标注册与租约、文件占用恢复、包结构/签名、安装器异常场景已经自动化验证。实机视觉、真实输入和实际帧率仍需验收，不用编译成功代替游戏运行结果。

## 安全与许可

应用不读取游戏内存、不注入、不 Hook、不模拟输入；只经本机 GSI、Game Bar 与可关闭的鼠标 Raw Input 工作。**这些设计边界不能换算为 VAC 零风险或平台许可**。赛事、第三方反作弊及服务器规则独立适用，详见[审查报告](docs/ANTI-CHEAT-REVIEW.md)。
