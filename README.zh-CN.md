## 能做什么

- **准心**：十字、圆环、实心圆与圆心；实时预览、抗锯齿、几何居中、方向键每次 1 物理像素。默认不随系统 DPI 放大尺寸。
- **击杀提示**：每次击杀独立条目；单矩形展开、纵向收束、四次方缓出；文字、颜色、位置和时间可调。
- **实时统计**：K/D/A、回合击杀、爆头击杀比例、可获得的伤害与经济；逐项显示模式、拖拽、网格与边缘吸附。
- **键鼠显示**：逐键 A/B 模式、可配置按键；鼠标左右中键/滚轮高亮；固定面板内自适应缩小轨迹，闲置归中。
- **显示性能**：视觉缓存、对象复用、轨迹批量绘制与同帧更新合并；1–240 FPS 自定义目标，空闲时停止动画刷新。

## 换电脑安装

1. 将 `ReticleLab-0.2.10-windows-x64.zip` 整包复制到新电脑并解压。
2. 运行 `Install-ReticleLab.cmd`。首次信任开发证书时会出现系统提权提示；安装继续在原用户账户进行。安装器自动关闭旧版目标包进程，保留配置。
3. 安装/启用 Xbox Game Bar，按 **Win + G** 打开并固定 Reticle 控件。
4. 如需 CS2 数据：在新电脑打开设置 → GSI → 启动/检查接收，然后运行 `Setup-GSI.cmd` 并重启 CS2。脚本探测 Steam 库，安装当前电脑生成的 GSI 配置。

系统要求：**Windows 10 build 19041+ 或 Windows 11 x64，以及 Xbox Game Bar**。安装包包含 .NET 运行时、微软 x64 依赖和开发证书，使用 MSIX 安装。详见[安装与故障排查](docs/INSTALL.md)。

## CS2 数据说明

| 显示 | 实际含义 |
| --- | --- |
| 武器名 | 当前手持兜底，不能确定为击杀武器 |
| 伤害数字 | 相邻本人 GSI 的 `round_totaldmg` 差值，标为“更新增量”；不是目标伤害 |
| 同次更新多杀 | 分别显示，同一更新总量重复标注，不能相加或均分成目标伤害 |
| 伤害缺失 / 0 | 无可靠增量时显示连杀序号；有效数据未增加时显示 0 |
| 爆头命中、身体命中 | 没有可靠逐次事件；按钮明确为样式演示 |
| 准备阶段降低透明度 | 整个冻结阶段，不是购买菜单检测 |

仅接受 provider 与 player 身份一致的本人参战数据。初次接入、重连不补播旧击杀。

## 开发与验证

Windows x64 + .NET SDK 10，执行 `native/scripts/build.ps1`；Python 3 与 Node.js 用于辅助烟测。源码包含 Noto 字体与应用图标。详见 [构建与签名](native/DEVELOPMENT-SIGNING.md)。

148 项核心检查、实际 HTTP 接收/鼠标注册与租约、文件占用恢复、包结构/签名、安装器异常场景已经自动化验证。实机视觉、游戏内输入、多屏居中、长时间稳定性和实际帧率仍需交互验证。

## 安全与许可

应用不读取游戏内存、不注入、不 Hook、不模拟输入；只经本机 GSI、Game Bar 与可关闭的鼠标 Raw Input 工作。这些设计不代表 VAC 认证，详见[反作弊审查](docs/ANTI-CHEAT-REVIEW.md)。
