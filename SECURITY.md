# Security and privacy

Do not place vulnerability details or live GSI tokens in public issues. If GitHub private vulnerability reporting is enabled for the eventual repository, use that channel. Otherwise request a private contact channel without including exploit details; no maintainer email or hosted repository is implied by this source snapshot.

The app binds only to IPv4 loopback, authenticates GSI using a generated token, limits request size/rate/concurrency, and retains only normalized self-state. Same-user local malware can still read the token or tamper with local files; this is not a security boundary against a compromised Windows account.

Mouse Raw Input sees mouse activity across foreground applications while the visible input widget renews its lease and the switch is enabled. It is not scoped exclusively to CS2. No background raw keyboard registration exists. Game Bar hotkey watchers cover only configured keys. No project runtime upload or telemetry endpoint is implemented; Windows, Game Bar and Microsoft dependencies have their own policies.

State, settings and logs are local to the package. Diagnostics may contain paths, process information, map/stat data and exception details. They are excluded from source/release exports. Do not share them unreviewed. The release public certificate and fingerprints are public by design; the private key/password are never distributed.

Read the [anti-cheat review](docs/ANTI-CHEAT-REVIEW.md) for the separate question of game/platform permission. This document does not certify compatibility with VAC or other anti-cheat systems.
