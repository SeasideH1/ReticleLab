# Reticle Lab 0.2.11

- 击杀提示在没有可靠伤害增量时显示连杀序号：1ST、2ND、3RD、4TH…；死亡或换回合后重置。同次更新多杀分别编号。存在有效伤害数据时优先显示伤害，真实 0 保留为 0。
- 中途连接或长时间断连后，从重新接收以来观察到的击杀开始计数，历史击杀不会重播。
- 准心固定显示时隐藏自身窗口的鼠标指针；打开 Game Bar 时恢复。固定显示的控件不再处理 XAML 点击聚焦，前台编辑功能保留。
- 显式允许本应用视图参与屏幕捕获。Windows / Game Bar 宿主与 OBS 捕获方式仍会影响录制结果，参见 [OBS 与指针排查](OBS-CAPTURE.md)。
- 接收器增加可选 `--inspect-gsi` 字段诊断，默认关闭；诊断不保存认证值、玩家身份值或其他玩家数据。

验证：148 项核心检查和原生 Widget 编译通过。连杀检查覆盖多杀拆分、死亡、重生、回合切换、重复报文、断线、0 伤害和英文序号后缀。鼠标指针与 OBS 实际录制效果仍需更新后的实机验证。

本次更新沿用应用标识，改用当前桌面账户保管的新开发证书。运行 `Update-ReticleLab.cmd` 后，Windows 会在需要时请求管理员授权信任包内证书；随后为原用户更新应用并保留配置。旧签名密钥已保留。
