演示数据与统计口径 GSI 接入边界

这是离线样式演示，未连接 CS2。击杀条展示使用的武器与造成伤害统计，示例为 AK-47 / 100；逐次命中与命中部位均为模拟数据。伤害统计的归属窗口待后续接入确定。动画时序可调；示意帧不是游戏截图。

HS Kill = 爆头击杀 ÷ 全部击杀；命中 HS = 头部命中次数 ÷ 全部命中次数。零分母显示 —。净增经济 = 回合结算后余额 − 该回合冻结阶段开始余额，包含购买支出。统计控件可选择一直显示，或仅在回合开始的准备阶段显示；模拟命中、击杀、死亡、助攻会实时更新；新回合清空本回合统计，保留累计伤害和金钱。模拟购买菜单打开时，统计卡整体不透明度降低，关闭后恢复。

正常参战 GSI 不能保证提供逐次命中、头部命中、可靠的击杀武器归属、即时伤害明细或购买菜单开关状态。实际接入前需要采集验证；“GSI 保守预览”将无法可靠提供的命中 HS 显示为 —。键鼠控件只读取获得焦点的预览内输入，不检测其它窗口；支持按键录入、点击高亮和有限时长的移动轨迹。方向键 1 px 为预览 CSS 像素，原生 Game Bar 需要另行换算 DPI 后的物理像素。
